# Analytics Sandbox

> A lower-polish space for SQL practice, quick data explorations, and notes from papers & books. Not every idea deserves its own repo.

## Contents

### 🧮 [sql-interview-problems/](sql-interview-problems/)
FAANG-style SQL problems solved in standard Postgres and Spark SQL. Each problem has the prompt, a solution, and a short explanation of the approach.

### 📊 [quick-explorations/](quick-explorations/)
1–2 hour EDAs on interesting public datasets. Scrappy by design — not every notebook needs a memo.

### 📚 [reading-notes/](reading-notes/)
Implementation notes from papers and books. Currently working through *Trustworthy Online Controlled Experiments* (Kohavi, Tang, Xu).
